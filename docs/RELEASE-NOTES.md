聊天附件与房间互动。

- 房间聊天、私信新增图片与 GIF 表情包上传：先预览，再确认发送。
- 私信增加最多 60 秒录音、MP4 视频及本地文件发送；普通文件上传到网易云存储后，以下载链接发送。
- 显示附件上传进度，支持取消上传、失败保留和手动重试；发送结果未知时不会自动重发。
- 切换账号或离开房间后重新核对目标，防止旧附件发到新的会话；麦克风和媒体预览在取消/离开时释放。
- 播放队列增加删除自己推荐歌曲、官方 UP 顶歌；删除按具体队列条目处理，保留其他相同歌曲推荐。
- 播放页增加独立的“一起听点赞”及数量，与个人红心收藏分开。

图片支持 PNG/JPEG/GIF/WebP，最大 20 MB；视频支持 MP4，视频和普通文件最大 100 MB。UP 遵循网易云的优先级规则，不保证立即移到第一位。

在“设置 → 应用更新”下载 0.11.0 并重启。新附件协议已静态核实并通过模拟测试；真实账号的上传、跨端收取及房间权限组合仍需实测，服务端拒绝会如实显示。
