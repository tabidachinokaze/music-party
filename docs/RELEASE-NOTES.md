播放界面重新设计，让音乐与一起听集中在同一个地方。

- 封面、歌曲信息和歌词同屏展示；点击底部封面随时返回播放界面。
- 歌词在独立区域内滚动，个人播放时可点击歌词跳转；多人模式跟随房间进度。
- 移除左侧“个人队列”和“歌词”入口，底部播放栏新增播放队列按钮。
- 个人模式显示个人播放队列；多人模式自动切换为官方房间待播列表，显示歌曲名称、歌手及可用的推荐者信息。
- 多人成员、同步状态、私信邀请、房间聊天、复制邀请和离开房间整合到播放界面。
- 开房/加入和登录改为弹窗；诊断记录移到设置，减少日常听歌时的界面干扰。
- 优化小窗口布局、浅色主题和提示信息。

可在应用设置中检查更新，下载后确认安装并重启。Linux 使用 AppImage；Windows 安装包暂未代码签名。macOS 尚未提供。

房间待播内容以官方接口当前返回为准；若待播总数超过返回的歌曲数量，会明确显示当前提供了多少首，后续随房间更新。
