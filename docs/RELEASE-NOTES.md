私信、收藏专辑与日常交互优化。

- 私信改为双栏独立滚动，调整联系人、时间、消息和输入区布局，适配小窗口与浅色主题。
- 接入官方单会话已读接口：打开并加载当前会话后同步已读，更新会话和侧栏未读角标；失败保留未读并支持重试，不清除其他会话。
- 新增“收藏的专辑”，自动加载全部收藏，支持查看专辑歌曲、播放全部和房间内推歌。
- 增加页面、播放页、弹窗和侧边面板的短时过渡动画；遵循系统减少动态效果设置。
- 修复全屏状态回传与重复点击问题，原生全屏完成后同步按钮状态；底部封面支持展开/收起。
- 最近搜索增加逐条删除按钮，并保留一键清空。
- 所有取消红心入口增加二次确认，确认后才提交移除。
- 弹窗、播放队列与聊天面板支持点击外部关闭，保留草稿；Esc 与焦点返回行为统一。

在“设置 → 应用更新”下载 0.9.0，确认安装并重启即可。提供 Linux AppImage 与 Windows 安装包。
