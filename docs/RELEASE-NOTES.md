网易云官方自定义表情同步。

- 表情面板新增“自定义表情”，读取当前账号的官方收藏，支持分页、刷新与多个可编辑分组。
- 新增“上传表情”：选择图片/GIF，预览并确认后保存到网易云官方自定义表情包；保存成功后自动刷新列表。
- 房间和私信均可直接发送收藏的表情，私信无需重新上传图片；输入框中未发送的文字会保留。
- 保留常用 Unicode 表情及房间最近使用的表情。
- 修复表情图片大整数 ID 的解析精度，按官方规则生成图片地址，避免出现错误或空白缩略图。

上传保存和聊天发送相互独立。保存结果未知时应先刷新列表确认，再手动重试；额度或权限限制按官方返回显示。

可在“设置 → 应用更新”升级至 0.12.0。协议与交互已通过模拟测试，真实账号与手机端的收藏同步仍需实际使用确认。
