首个公开试用版，欢迎反馈问题。

支持网易云官方多人一起听：创建和加入房间、同步播放、推歌与切歌、成员列表、房间聊天、私信邀请。另包含歌单与喜欢列表、搜索、歌词、个人播放队列、托盘和主题设置。

本版本内置应用更新：设置 → 应用更新 → 检查更新 → 下载更新 → 安装并重启。发现新版本不会自动下载或中断一起听；安装前会尝试退出当前房间。GitHub 项目和反馈入口也在设置页。

下载说明：

- Linux x64：下载 `.AppImage`，授予执行权限后直接运行。应用内更新需要 AppImage 本身及其目录可写。
- Windows x64：下载 `.exe` 安装包。当前试用包尚未代码签名，系统可能显示未知发布者提示。
- macOS 尚未提供经过签名和验收的安装包。

`latest.yml`、`latest-linux.yml` 和 `.blockmap` 是应用更新所需文件，通常无需手动下载。已有 0.6.x 或更早版本需要手动安装一次本版本，之后可从应用内更新。

当前播放和聊天仍采用轮询，可能存在短暂延迟。更多消息类型、云信即时推送及其他平台适配仍在完善。
