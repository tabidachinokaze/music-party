播放界面现在可以占满窗口，并支持真正的系统全屏。

- 点击底部封面、左侧“正在播放”或“展开”，隐藏侧栏和顶部导航，集中显示封面、歌词与一起听信息。
- 右上角“全屏”进入系统全屏；“退出全屏”回到窗口，左上角“收起”返回原页面。
- Esc 优先关闭弹窗或队列/聊天，再退出系统全屏，最后收起播放页。
- 展开/收起保留搜索内容和结果，不中断音乐或多人房间同步；队列与聊天仍从底部播放栏打开。
- 系统菜单切换全屏时界面状态同步，全屏退出应用后仍记住普通窗口尺寸。
- 优化完整窗口、小窗口和浅色主题下的封面与歌词布局。

在“设置 → 应用更新”检查并下载 0.8.1，确认安装后重启即可使用。Linux 使用 AppImage，Windows 使用 NSIS 安装包。
