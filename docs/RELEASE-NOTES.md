Music Party 0.13.0 正式版：私信通知、房间交互与播放器自定义。

- 私信接入 Mini 长连接，后台收信；播放页右上通知气泡可打开对话并直接回复。增加联系人在线查询、在线优先排序、已读同步和会话草稿保存。
- 房间聊天卡片与输入框对齐模组，支持 Emoji、颜文字、表情包、图片和成员提及。Enter 换行，Ctrl/Cmd+Enter 发送；私信专辑卡片在应用内部打开。
- 各类列表滚动自动加载，聊天上拉补历史并保持阅读位置；表情收藏、上传和删除保留已加载内容。
- 增加独立匹配用歌、公开好友房和陌生人匹配/取消/重新匹配，成员页显示待播与已播推荐。
- 当前歌曲和待播歌曲显示推荐者或“系统推荐”，一起听点赞可重复点击；播放页可将当前歌曲添加到自己的歌单。
- 歌曲分享支持本地试听；试听时点击停止退出并恢复房间歌曲、进度和原来的本机暂停状态。
- 顶部导航统一承载页面标题与搜索，移除内容区重复标题和房间状态提示，优化各页面内边距与小窗口布局，操作提示不再挤动页面。
- 增加整个播放器的自定义背景图片，支持缩放、位置、透明度和模糊；房间聊天及待播面板使用不透明主题背景，避免底层歌词透出。
- 外观设置支持 80–150% 界面字号和自定义强调色；音量支持滚轮调整并显示百分比。

可在“设置 → 应用更新”升级至 0.13.0，或从本页下载 Windows x64 安装包、Linux x64 AppImage。

联系人在线查询不包含本客户端自身在线上报；房间歌曲与聊天仍使用心跳和历史同步。接口与验证范围见仓库的 `docs/PROTOCOL-GUIDE.md`。
