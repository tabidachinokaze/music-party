Music Party 0.13.1 将音乐库、正在播放、房间聊天和私信整合到一个随窗宽调整布局的播放器中。

- **单窗口播放。** 点底栏封面展开正在播放页。宽窗可并排查看封面和歌词，窄窗点「词」阅读完整歌词。调整窗口大小后，仍可回到刚才的页面和搜索结果。
- **一起听。** 点播放栏的耳机按钮加入、创建或匹配房间。「切换歌曲」可直接搜索匹配用歌，搜索历史按账号保存。成员页跟随官方聊天室推送更新在线人数和名单，头像和昵称在资料到达后补齐。
- **退房后继续听。** 主动退房时，已播、当前和待播歌曲按顺序转入个人队列，同一首歌被推荐多次也会保留。当前歌曲接着播放，本机已暂停时保留暂停位置。
- **重新打开播放器。** 个人队列按账号保存，重启后停在上次选中的歌曲，从曲首开始。若退出应用时还在房间，同一账号下次启动时会向网易云确认房间状态，仍在原房即可接回当前进度。
- **四种界面语言。** 播放器和桌面菜单默认跟随系统，可在「设置 → 外观」随时切换简体中文、繁體中文、English 或日本語。这里也可以分别调整布局、组件和弹窗的背景透明度。

从 0.13.0 升级可在「设置」中打开「应用更新」，或从本页下载 Windows x64 安装包或 Linux x64 AppImage。[单窗口播放器使用说明](https://github.com/tabidachinokaze/music-party/blob/v0.13.1/docs/ADAPTIVE-PLAYER.md)
