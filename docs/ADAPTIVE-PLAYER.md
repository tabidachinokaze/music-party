# 单窗口播放器使用说明

适用于 `redesign/adaptive-player` 分支，以 Windows 测试版 `0.13.1-adaptive.21` 为准。正式版 0.13.0 用户可从[第一次一起听](../README.md#第一次一起听)开始。

## 浏览与播放

点底栏封面展开正在播放页，点左上角箭头返回。窄窗点「词」可看完整歌词。手动翻阅后点「回到当前歌词」继续跟随。

顶部搜索框随页面切换用途。在「搜索」页可查歌曲、歌单和歌手，打开歌单或专辑后可筛选其中的曲目。「添加到歌单」支持跨搜索勾选多个自建歌单，再一次确认。个人队列按账号保存，重启后恢复到上次的歌曲并暂停。

## 一起听

- **进房或开房**。点播放栏的耳机按钮，粘贴好友的多人邀请链接，或选择「恢复当前房间」。要创建或匹配房间，点「切换歌曲」搜索匹配用歌，选好后点「用当前歌曲创建」或「匹配房间」。结果中的红心表示自己的收藏状态，选歌时收藏状态保持原样。
- **在房间里**。点在线人数查看成员，头像和昵称可能稍后补齐。房间队列的「正在听」显示当前和待播歌曲，「听过的」显示播放历史。播放栏的点赞用于当前房间歌曲，红心用于个人收藏。
- **退出房间**。已播、当前和待播歌曲依次转入个人队列，重复推荐也会保留。当前歌曲接着播放，本机已经暂停时保留暂停位置。
- **退出应用**。下次用同一账号启动时，如果网易云确认你仍在原房间，播放器会接回房间的当前进度。

## 私信与外观

从「私信」打开完整会话，收到通知时可点击快捷回复。按 Enter 换行，按 Ctrl/Cmd+Enter 发送。发送附件后若结果不明确，先刷新会话确认是否送达。

在「设置 → 外观」切换中英文、主题或整体显示大小。点「编辑背景」导入图片，调整焦点、缩放、模糊和图片透明度。想看清原图，可先设图片透明度为 0%、布局背景透明度为 100%，再分别调整组件与弹窗的底色。

遇到同步问题可从「设置 → 更新与帮助 → 观测记录」导出记录，其中保留用户、房间和歌曲 ID。跨端实测范围见[验证记录](VALIDATION.md)。开发时可查阅[界面规范](UI-GUIDELINES.md)和[页面与接口数据](ui-data/README.md)。
