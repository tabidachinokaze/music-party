# 验证记录

## 官方服务与真实账号

| 场景                  | 已观察到的结果                                                                                                                                                                                                                   |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 桌面与官方 App 一起听 | 0.2.1 用户实测可恢复房间、通过邀请链接加入、跟随播放、推歌和请求下一首。记录未注明同房账号数和操作者角色。                                                                                                                       |
| 开房被拒              | 用户提供的请求以 `songId=0` 建房，HTTP 请求成功，业务返回 `MULTI_SONG_NOT_SATISFIED`。0.3.0 起桌面要求先选有效歌曲。成功创建及不同权限组合仍待跨端测试。                                                                         |
| 成员人数与名单        | 早期成员缺失可追溯到读取了错误的 JSON 字段，已改为 `multiLtRoomUserAgg`。后来在真实房间收到云信 30005 推送，一次样本中 `onlineNums=5`，同条消息解析出 5 名成员。人数与资料缺失时分别核对这两个值。详见[成员同步样本](LT-IM.md)。 |
| 私信房间邀请          | 0.5.1 补齐官方 App 邀请卡片内嵌链接的解码后，用户确认私信邀请可用。                                                                                                                                                              |
| 匿名访问              | 独立安装包通过内置 API 取得登录二维码，可搜索歌手、读取歌词并实际播放歌曲。有效多人邀请预览返回 `AVAILABLE`，匿名查询账号房间状态返回 `302`。                                                                                    |

0.1.0 验证的是双人接口。上表中的多人互通结论从 0.2.x 开始；涉及不同角色、长期运行或手机端接收的待测场景见[开发计划](ROADMAP.md)。

## 正式版与安装包

- **0.13.0** 在 Linux x64 / Wayland 通过冻结依赖安装、类型和格式检查、340 项单元测试、14 项 Electron 桌面测试及生产构建。桌面测试用模拟账号和接口覆盖音乐库、房间、私信、附件和外观。正式版与 `0.13.0-test.20261010.5` 使用相同的业务源码。[0.13.0 发布说明](https://github.com/tabidachinokaze/music-party/releases/tag/v0.13.0)
- **Linux 桌面与更新**在独立 AppImage 上验证了关闭到托盘继续运行，以及 0.7.0 从隔离的本地更新源升级至 0.7.1。重启后核对了安装文件 SHA-512 和实际版本。原生全屏在 KDE / Wayland 验证。[发布手册](RELEASING.md)

## 单窗口开发版回归

以下记录来自 Linux Electron 与模拟账号。自 `0.13.1-adaptive.16` 至 `.21`，每版 Windows x64 压缩包均已核对归档完整性及包内构建文件。Windows 原生显示与系统交互仍需实机复核。

| 测试版                     | 已覆盖的行为                                                                                                                                                    |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `.9` 至 `.15` 中的布局回归 | 三档窗宽、150% 显示比例、常显滚动条、歌曲行断点、搜索焦点、聊天工具切换及跨筛选多选歌单。                                                                       |
| `.16` 至 `.19`             | 退出应用后可接回原房，主动退房则将已播、当前及待播歌曲转入个人队列。另验证房间点赞、人数角标、中英文切换、歌词高度及队列歌手跳转。                              |
| `.20`、`.21`               | 覆盖创建者与邀请人身份区分、选歌与重新匹配；匹配搜索历史按账号隔离，重启可恢复。点击搜索结果的红心只选择歌曲。`.21` 构建时通过 373 项单元测试和 18 项桌面回归。 |

复测当前工作区运行 `pnpm run check`。构建完成后，在有图形会话的环境中运行 `pnpm test:desktop`。手动复测可用 `MUSIC_PARTY_PROFILE` 指定独立数据目录。Linux 无图形会话时的依赖及启动命令见 [CI 工作流](../.github/workflows/ci.yml)。
